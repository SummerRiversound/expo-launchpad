# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security concern. Instead:

- Open a [private security advisory](https://github.com/SummerRiversound/expo-launchpad/security/advisories/new), or
- Email the maintainer at `42575126+SummerRiversound@users.noreply.github.com`.

Include what you found, how to reproduce it, and its potential impact. We'll acknowledge the
report and work with you on a fix before any public disclosure.

## Credentials and secrets

The plugin never commits credentials, and Phase A (idea → playable) does not collect any secrets
or API keys as part of its pipeline. If you find a secret committed anywhere in this repo, please
report it using the channels above.
